# 실습 문서 준비

이 폴더의 PDF 파일은 Git 저장소에 포함하지 않습니다.

실습에는 대한의학회·질병관리청의 `일차 의료용 우울증 임상진료지침`을 사용합니다.

1. 공식 페이지 <https://guideline.or.kr/chronic/view.php?number=98>에서 문서를 확인합니다.
2. PDF를 내려받아 이 폴더에 넣습니다.
3. 파일명을 `우울증임상진료지침_대한의학회.pdf`로 맞춥니다.
4. 프로젝트 루트에서 `python .\stage2_demo.py`를 실행합니다.

문서의 이용 및 재배포 조건은 원 발행기관의 안내를 따릅니다.
