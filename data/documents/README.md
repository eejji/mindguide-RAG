# 실습 문서 준비

이 폴더의 PDF 파일은 Git 저장소에 포함하지 않습니다.

실습에는 대한의학회·질병관리청의 `일차 의료용 우울증 임상진료지침`을 사용합니다.

1. 공식 페이지 <https://guideline.or.kr/chronic/view.php?number=98>에서 문서를 확인합니다.
2. PDF를 내려받아 이 폴더에 넣습니다.
3. 파일명을 `우울증임상진료지침_대한의학회.pdf`로 맞춥니다.
4. 한 페이지 청킹을 확인하려면 프로젝트 루트에서 `python .\stage2_demo.py`를 실행합니다.
5. 웹 데모용 전체 검색 인덱스는 `python .\stage7_demo.py`로 준비합니다. 이 명령은 같은 이름의 기존 로컬 Qdrant 컬렉션을 삭제 후 재생성하므로, 보존할 데이터가 있으면 실행하지 마세요. 앱을 중지하고 수행합니다.

파일 확인 기준: PDF 152페이지 중 텍스트가 있는 136페이지, 300자·overlap 50자로 747개 청크입니다. PDF 파일이나 추출 라이브러리 버전에 따라 결과가 달라질 수 있습니다.

문서의 이용 및 재배포 조건은 원 발행기관의 안내를 따릅니다.
